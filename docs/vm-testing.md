# Тестирование в виртуальной машине (главный стенд)

Настоящий ASUS X550EA трогаем только после полностью рабочего образа в VM.

## VirtualBox — рекомендуемые настройки
| Параметр | Значение |
|---|---|
| Тип / версия | Linux / Other Linux (64-bit) |
| RAM | 2048 МБ минимум, лучше 4096 МБ |
| CPU | 2 |
| EFI | выкл (BIOS хватает), чипсет PIIX3 |
| Графика | **VMSVGA, 128 МБ видеопамяти, 3D-ускорение ВЫКЛ** |
| Носители | CD: ISO в IDE/SATA-контроллере; диск 8 ГБ (для будущей установки) |
| Сеть | NAT |
| Указывающее устройство | PS/2 мышь или USB-планшет |

В образ вшиты: xf86-video-vmware/vesa/fbdev (фолбэки под VMSVGA/std VGA),
xf86-input-evdev+libinput, **VirtualBox Guest Additions** (общий буфер,
интеграция мыши, авторазмер экрана). На настоящем X550EA гостевые службы
просто не найдут /dev/vboxguest и не помешают.

## Критерии «полностью работоспособна» в VM
1. GRUB → нет ошибок init, появляется белая заставка Dreamcast со свёрлом.
2. Enter → XMB: стрелки ходят по категориям, волна анимируется.
3. Открываются Настройки (смена темы), Заметки (печатается текст), Игры.
4. Терминал (xterm) открывается на весь экран; выход — красная кнопка ВЫХОД вверху справа, `Home`/`Super`/`F9`/`Ctrl+Esc` или Guide на геймпаде.
5. Перезагрузка из VM проходит чисто.
