# Оптимизация XrossOS под ASUS X550EA

Эталон: **AMD A4-5000 (4× Jaguar 1.5 ГГц) + Radeon HD 8330 (GCN 1.0) +
экран 1366×768 + 4 ГБ DDR3L + HDD 5400**. Это очень слабое железо 2013 года,
поэтому вся система проектировалась от него, а не «в среднем».

## Процессор (Jaguar / btver2)
| Мера | Зачем |
|---|---|
| `make` по умолчанию `-march=btver2 -mtune=btver2 -O2 -flto` | AVX/SSE4.2 планировщик именно Jaguar; бинарь оболочки ~60 КБ |
| Только libX11, без Cairo/Pango в оболочке | Меньше кода — больше L2 (2 МБ на весь APU) |
| 60 FPS от сети / **30 FPS от батареи** (читает `BAT0`/`ADP1` из `/sys`) | Половина кадров = заметно дольше батарея |
| Нет композитора (нет picom), программный Pixmap-рендер | HD 8330 слаб в glamor-композитинге окон; ядро X11 быстрее |
| Волна PS3: шаг 8 пкс (~170 точек на 1366) | Три полилинии не грузят одно ядро Jaguar |

## Графика (Radeon HD 8330, GCN 1.0)
- Драйвер **amdgpu**, не radeon: `amdgpu.si_support=1 radeon.si_support=0` в cmdline ядра + `os/overlay/etc/modprobe.d/x550ea-amdgpu.conf`.
- Mesa **radeonsi**, `AccelMethod glamor`, DRI3, `TearFree on` — `os/overlay/etc/X11/xorg.conf.d/20-x550ea-amdgpu.conf`.
- VA-API через radeonsi для mpv (`--hwdec=vaapi`): Jaguar не тянет 1080p софтом, а панель всё равно 768p — капить видео 720p.
- **XLibre** вместо X.Org где доступен пакетом: тот же протокол X11, наша оболочка не зависит от сервера (только libX11 на клиенте).

## Память и диск
- **zram lz4 50% RAM** + `vm.swappiness=100` (swap в сжатую RAM, не на HDD).
- HDD: планировщик `mq-deadline` (udev-правило в overlay), `noatime`, tmpfs на `/tmp`.
- Честный совет в README образа: SSD и вторая планка RAM дают больше, чем любой тюнинг.

## Периферия
- Тачпад через libinput (тап, disable-while-typing) — `30-x550ea-input.conf`.
- Wi-Fi MT7630e в некоторых ревизиях: нужен `mt76`/фирмварь из linux-firmware; AR9485 работает из коробки (ath9k).
- HDMI/VGA: RANDR из XLibre, оболочка сама перечитает размер при `ConfigureNotify`.

## Проверка на живом железе
```sh
xross --version            # xross 0.2 (Swirl)
glxinfo | grep renderer    # AMD KABINI / radeonsi
vainfo                     # VA-API профили HD 8330
cat /sys/class/power_supply/BAT0/capacity
```
