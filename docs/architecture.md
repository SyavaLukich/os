# Архитектура XrossOS 0.2 «Swirl» (C / X11-XLibre)

Раньше (0.1) оболочка была веб-страницей на JS под Wayland/Cage. **0.2 —
полный рерайт на C поверх Xlib** (работает с XLibre и классическим X.Org).

```
┌────────────────────────────────────────────────────────┐
│ Внешние приложения: Firefox, mpv, RetroArch, Kodi, xterm│
│   ▲ MapRequest перехватывает xross-WM → весь экран      │
├────────────────────────────────────────────────────────┤
│ xross (src/xross.c, ~60 КБ, только libX11+libm)        │
│  XMB (PS3/PSP) · орбита-сферы (PS Vita)                │
│  Dreamcast: белая заставка, вращающийся свёрл, меню 4 сфер│
│  встроенные приложения и игры · геймпад js0 · батарея  │
├────────────────────────────────────────────────────────┤
│ Голос: arecord → xross-voiced (C, Vosk, dlopen) → FIFO │
│        → команды оболочки · ответы espeak-ng -v ru     │
├────────────────────────────────────────────────────────┤
│ XLibre / Xorg · amdgpu+radeonsi (HD 8330) · libinput   │
├────────────────────────────────────────────────────────┤
│ Alpine Linux · ядро LTS · OpenRC · zram · TLP          │
│ Эталон железа: ASUS X550EA (docs/x550ea.md)            │
└────────────────────────────────────────────────────────┘
```

## Почему X11/XLibre, а не Wayland
- На GCN 1.0 + Jaguar связка XLibre + radeonsi предсказуемее Wayland-композиторов.
- Оболочка одновременно является WM: `SubstructureRedirectMask` на root,
  в `MapRequest` каждое чужое окно получает `0,0,W,H` и бордер 0. Оконного
  режима не существует в принципе — как раньше гарантировал Cage.
- Возврат из приложения: `Ctrl+Esc` / `Home` (граб на root) или закрытие окна.

## Референсы интерфейсов
| Консоль | Что взято |
|---|---|
| PS3 | XMB: категории горизонтально, пункты вертикально, живая волна, темы |
| PSP | Лёгкость, читаемость на 1366×768, управление крестовиной |
| PS Vita | Сферические иконки-«пузыри», мини-игра «Пузыри» |
| **Dreamcast** | Белая загрузочная заставка, вращающийся **свёрл** (цвет по «регионам»: EU синий / JP оранжевый / US красный), орбитальное меню из 4 сфер (Play/File/Music/Settings), F1 переключает XMB ↔ Dreamcast |

## Производительность (X550EA)
Программный рендер в Pixmap-даблбуфер, предрендер градиента в кэш-Pixmap,
кэш цветов (не `XAllocColor` на кадр), шаг волны 8 пкс, адаптивный FPS
60/30 по питанию от `BAT0/ADP1`. Сборка: `-march=btver2` (см. `src/Makefile`).

## Голос
Команды (ru): «вправо/влево/вверх/вниз», «выбери», «открой музыку/файлы/
настройки/…», «домой», «который час», «помощь». Логика — `voice_handle()`
в `src/xross.c`; распознавание — `src/xross-voiced.c` (Vosk офлайн).
