# Архитектура XrossOS

```
┌─────────────────────────────────────────────────────┐
│ Приложения: Firefox, mpv, игры, установленные пакеты │
│   ▲ запуск ТОЛЬКО через xross-launch → Cage          │
├─────────────────────────────────────────────────────┤
│ Оболочка XMB (shell/) — HTML/CSS/JS, ноль зависимостей│
│  волна Canvas · анимации CSS · WebAudio · Gamepad API │
├──────────────┬──────────────────────────────────────┤
│ Голос: Vosk  │  Cog (WPE WebKit) — рендер оболочки   │
│ (офлайн, ru) │                                      │
├──────────────┴──────────────────────────────────────┤
│ Cage — Wayland kiosk-композитор: 1 окно = весь экран │
├─────────────────────────────────────────────────────┤
│ Alpine Linux 3.20 · ядро LTS · OpenRC · PipeWire     │
└─────────────────────────────────────────────────────┘
```

## Почему так легко
- **Alpine + musl + BusyBox** вместо Debian/systemd: база ~130 МБ, загрузка ~6 с.
- **Cog/WPE WebKit** вместо Chromium/Electron: оболочка ест ~120 МБ ОЗУ.
- Оболочка — чистый JS без сборки и npm: `shell/` просто копируется в образ.

## Полноэкранный режим — гарантирован, а не «попрошен»
Cage по дизайну не умеет окна: у него одно полноэкранное окно. Сторонние
приложения запускаются скриптом `xross-launch <app>` (обёртка `cage -s -- …`),
поэтому свернуть/уменьшить их невозможно в принципе. В веб-прототипе то же
поведение эмулируется `requestFullscreen()` + оверлеем `#app` на весь экран.

## Голосовое управление
| Режим | Движок | Интернет |
|---|---|---|
| Веб-прототип | Web Speech API (`webkitSpeechRecognition`, ru-RU) | нужен (Chrome) |
| Образ ОС | **Vosk** + модель `vosk-model-small-ru` (~40 МБ), демон `xross-voice` | не нужен |

Команды (ru): «вправо/влево/вверх/вниз», «выбери», «открой музыку/настройки/…»,
«домой», «во весь экран», «который час», «помощь». Добавление команды — одна
строка в `shell/js/voice.js` (`handle()`).

## Сторонние приложения в XMB
Киньте JSON в `/usr/share/xross/apps/`:
```json
{ "id": "firefox", "cat": "network", "title": "Firefox", "icon": "🦊",
  "exec": ["xross-launch", "firefox"] }
```
Оболочка подмешает его к `XROSS_APPS` (в прототипе список в `shell/js/apps.js`).

## Интерфейс (отсылки)
- **PS3** — XMB: горизонтальные категории, вертикальные пункты, живая «волна».
- **PS Vita** — круглые «пузыри» (мини-игра и форма иконок), свайпы.
- **PSP** — компактность, работа от геймпада и на слабом железе.
Анимации: `cubic-bezier(.22,1,.36,1)`, 60 FPS на трансформациях (не на layout),
отключаются в Настройках для слабого железа.
